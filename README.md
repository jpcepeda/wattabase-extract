# Wattabase : Extraction de données

Extraction automatique du texte et des métadonnées des deux premières pages

## Prérequis

- [uv](https://docs.astral.sh/uv/) (gère Python et les dépendances, rien d'autre à installer)
- Une connexion internet (téléchargement du PDF depuis Géorisques)

## Lancer le projet

bash
```
git clone https://github.com/jpcepeda/wattabase-extract.git test-technique
cd test-technique/wattabase-extract/
uv run extract.py
